## 🧩 About

**Torchlight 2 External Menu** is a curated list of Torchlight 2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, minimap overlay, loot highlighter
- **Quality-of-Life Helpers** — inventory manager, skill planner, overlay notes
- **Research Notes** — combat layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

## ✨ Features

### ESP
- Loot Highlighter — highlight items on the ground
- Minimap Overlay — enlarged map with markers
- Skill Planner — plan builds with notes
- Playback Speed — adjust game speed for study (0.1x to 5x)

### Wallhack
- Item Catalog — browse items, stats, and set bonuses
- Custom Skin Notes — organize character cosmetics
- Transparent UI — improved visibility of UI elements

### Aimbot
- Combat Log — record and review combat data
- Stat Tracker — track character stats during study
- Config Editor — edit game settings with presets
